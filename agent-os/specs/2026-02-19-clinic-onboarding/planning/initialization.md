## Raw Description

Clinic onboarding feature for the Mamirri physiotherapy app. This feature is part of the multi-tenancy capability that allows the system to support multiple clinics, where each clinic can have multiple therapists and patients.

Based on field testing feedback (Week 9), this feature addresses the need for:

- Creating and managing clinic entities
- Associating therapists with clinics
- Associating patients with clinics
- Proper data isolation between clinics

This builds upon the multi-tenancy foundation established in task 9.8.
