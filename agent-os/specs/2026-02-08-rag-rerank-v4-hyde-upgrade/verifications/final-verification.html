7. Configuration Details

Feature Flag

  • Name: ENABLE_HYDE
  • Default: false (disabled for safety)
  • Purpose: Enable/disable HyDE synthetic passage generation
  • Behavior: When false, system uses original query; when true, generates hypothetical documents for improved retrieval

API Requirements

  • Cohere API Key: Required for reranking (rerank-v4.0-pro)
  • Gemini 3 Flash API: Required when ENABLE_HYDE=true
  • Fallback: System gracefully degrades if API keys missing or APIs fail
