# Product Tech Stack

## Framework & Runtime
- **Application Framework:** NestJS (Backend), React 19 + Vite (Frontend)
- **Language/Runtime:** TypeScript / Node.js
- **Package Manager:** pnpm

## Frontend
- **JavaScript Framework:** React 19.2
- **CSS Framework:** Tailwind CSS
- **UI Components:** Shadcn/UI

## Database & Storage
- **Database:** PostgreSQL 16 (with pgvector for RAG)
- **ORM/Query Builder:** Prisma
- **Storage:** S3 Compatible (AWS S3 or Supabase Storage)

## AI & Services
- **Transcription:** OpenAI Whisper API (whisper-large-v3 using trough groq)
- **Intelligence & Vision:** Gemini 3
- **Vector Search:** pgvector (PostgreSQL) or ChromaDB

## Testing & Quality
- **Test Framework:** Jest
- **Linting/Formatting:** ESLint, Prettier

## Deployment & Infrastructure
- **Containerization:** Docker (for local development and deployment)
- **CI/CD:** GitHub Actions (preferred)
