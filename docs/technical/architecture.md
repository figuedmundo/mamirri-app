# System Architecture

## Overview
PhysioCopilot uses a modular monolith architecture built with:
- **Frontend:** React + Vite + Shadcn/UI
- **Backend:** NestJS + Prisma ORM
- **Database:** PostgreSQL (with pgvector extension)
- **Storage:** MinIO (S3-compatible)
